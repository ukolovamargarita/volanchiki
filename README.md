# Volanchiki — новостные инсайты для руководителей крупного бизнеса

Хакатон «Альфа-Будущее»: Новостная аналитика для принятия бизнес-решений.

Сервис берёт **клиента** (юрлицо из обезличенной выборки) и **событие** (новость или тема), возвращает **персональный инсайт**: что произошло, почему это важно именно этой компании, как событие оценивает Альфа-Банк, какие риски и возможности, что делать дальше.
> **Демо:** `https://ВАШ-ДОМЕН` (впишите после деплоя) · **Версия для проверки:** commit `ВПИШИТЕ_HASH`

## Что видит пользователь

1. **Главный экран** макета Альфа-Бизнеса с заметным виджетом «Новостные инсайты» и боковой кнопкой — постоянная точка входа.
2. **Выбор клиента** из демо-списка или поиск; справа профиль: вид деятельности, выручка, регион, группа, продукты банка.
3. **Выбор события**: готовые темы из аналитики банка или своя новость (любой текст).
4. **Инсайт** по шести вопросам кейса, с бейджами происхождения:
   - 🟦 **Факт из источника** (синяя рамка) — что произошло;
   - 🟥 **Позиция Альфа-Банка** (красная рамка) — только из аналитических материалов банка;
   - 🟪 **Вывод AI** (фиолетовая рамка) — гипотеза модели по данным о компании.
5. **«Как мы это посчитали»** — трассировка шагов агента; **«На чём основан вывод»** — источники и цитаты.


## Структура репозитория

```
├── src/Volanchiki.Api/        бэкенд на .NET 8
│   ├── Controllers/           REST: health, companies, insights
│   ├── Agent/                 оркестратор и инструменты агента
│   ├── Data/                  загрузка CSV и txt, хранилища в памяти
│   ├── Llm/                   клиент к LLM-шлюзу, выбор модели по роли
│   └── Domain/                модели компании, инсайта, трассировки
├── frontend/                  React + TypeScript + Vite
│   └── src/components/        виджет, выбор клиента/события, инсайт, трассировка
├── read_only/                 данные кейса (CSV клиентов, txt аналитики банка)
├── deploy/                    nginx, systemd — для деплоя на свой сервер
├── docs/DEPLOY.md             пошаговый деплой
├── Dockerfile, docker-compose.yml   запуск одной командой
├── postman/                   коллекция запросов
└── THIRD_PARTY_NOTICES.md
```

## Запуск

Нужно: **.NET SDK 8** и **Node.js 20+**.

```bash
cp .env.example .env        # впишите LLM_API_KEY
```

**Бэкенд** (порт 5080):
```bash
dotnet run --project src/Volanchiki.Api --launch-profile http
```

**Фронтенд** (порт 5173, `/api` проксируется на бэкенд):
```bash
cd frontend
npm install
npm run dev
```
Откройте http://localhost:5173.

**Только интерфейс без бэкенда и ключа** (заглушки):
```bash
cd frontend && npm install && npm run dev:mock
```

**Одной командой через Docker:**
```bash
docker compose up --build   # http://localhost:8080
```

Деплой на сервер без Docker: [docs/DEPLOY.md](docs/DEPLOY.md).
## Масштабирование и поддержка

Новые отрасли и клиенты — это новые строки в CSV; новые источники аналитики — новые txt/PDF в `read_only/from_alfa` (хранилище читает каталог целиком); новые инструменты агента — класс, реализующий `IAgentTool`, и одна строка регистрации в `Program.cs`.
